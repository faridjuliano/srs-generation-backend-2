This folder should contain the IEEE SRS DOCX template used by the export feature.

Place the template file here as:

  templates/ieee-srs-template.docx

Notes:
- The export implementation expects a Word .docx file named `ieee-srs-template.docx` in this folder.
- Only Section 4 and Section 5 of the template should contain Docxtemplater placeholders as described in `copilot-docx-export-instructions.md`.
